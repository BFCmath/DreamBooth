# HyperHuman: Pipeline Overview and Multi-Stage Strategy

HyperHuman is a structural-aware human generation model that decomposes the synthesis task into two cascaded stages.

---

## Stage 1: Latent Structural Diffusion (G1)
**Objective:** Predict high-fidelity structural maps (Depth and Normal) directly from a sparse "Skeleton" (Pose).

### 1. Training Phase
*   **Input:** Text Prompt + Pose Map + Ground Truth (RGB, Depth, Normal).
*   **Learning Goal:** The model learns the joint distribution of RGB-D-N modalities conditioned on pose. 
*   **Outcome:** A U-Net backbone that understands spatial volumes—given a skeleton, it can accurately infer the corresponding 3D structure (surface normals and depth).

### 2. Inference Phase
*   **Input:** **Text Prompt + Pose Map**.
*   **Output:** **Joint Structural Predictions**: Low-resolution RGB ($\hat{x}$), Depth map ($\hat{d}$), and Normal map ($\hat{n}$).
*   **Rationale:** By utilizing a "Joint-Denoising" approach, the model hallucinate consistent 3D structural indicators from sparse 2D pose inputs.

---

## Stage 2: Structure-Guided Refiner (G2)
**Objective:** Utilize the structural maps from Stage 1 as geometric constraints for high-resolution (1024px) synthesis via SDXL.

### 1. Training Phase
*   **Input:** Text Prompt + High-Res RGB (1024px) + Structural Maps (Pose, Depth, Normal extracted from ground truth).
*   **Learning Goal:** Learn to use structural maps as a "template" for hyper-realistic rendering using a frozen SDXL backbone with trainable control units.

### 2. Inference Phase
*   **Input:** 
    1. **Text Prompt + User Pose** (User-provided).
    2. **Depth ($\hat{d}$) + Normal ($\hat{n}$)** (Generated by the Stage 1 model).
*   **Process:** Fuses all structural cues (Pose + Depth + Normal) into a unified guidance signal for the SDXL refiner.
*   **Output:** **Final 1024x1024 Hyper-Realistic Image.**

---

## Application Example: Unitree Robot Pose Transfer
1.  **Pose Input:** Provide the target pose of a robot.
2.  **Stage 1:** Generates estimated Depth and Normal maps for the robot in that specific pose (even without a reference 3D model).
3.  **Stage 2:** Uses these structural templates to render a highly detailed **Unitree Robot** in the desired configuration.
